# همراه هوشمند ماینکرفت (AI Player) — نسخه دوگانه جاوا (Fabric 1.20.6) و بدراک (Add-On 1.21+)

> **کاملاً آفلاین، بدون نیاز به هیچ مدل زبانی (LLM)، بدون API Key، بدون سرور ابری و بدون اینترنت.**

پروژه **AI Player** یک همراه هوشمند، بقا‌محور و خودکار برای هر دو نسخه اصلی ماینکرفت است:
1. **نسخه جاوا (Minecraft Java Edition 1.20.6 — Fabric)** با موجودیت انسانی، کوله‌پشتی واقعی ۳۶ خانه‌ای، ساخت ابزار، مسیریابی A* سه‌بعدی، ساخت‌وساز از روی نقشه (Blueprint) با مصرف واقعی منابع و ذخیره‌سازی کامل NBT.
2. **نسخه بدراک (Minecraft Bedrock Edition 1.21+)** شامل بسته رفتاری (`AIPlayer_BP`) و بسته منابع (`AIPlayer_RP`) بر پایه API پایدار `@minecraft/server` نسخه `1.11.0`.

---

## ویژگی‌های کلیدی مغز محلی (Offline Deterministic Brain)

- **درک دستورات فارسی و انگلیسی بدون LLM**: نرمال‌سازی کامل حروف عربی/فارسی (`ي/ی`، `ك/ک`)، نیم‌فاصله‌ها، اعداد فارسی (`۰-۹`) و استخراج دقیق تعداد، نام منابع، سبک ساخت‌وساز و نام بازیکن.
- **بازی واقعی در حالت بقا (Survival)**: بدون ساخت جعلی آیتم‌ها، بدون استفاده از `/give` و بدون تلپورت مخفیانه.
- **زنجیره وابستگی ساخت ابزار و ساخت‌وساز**: برای ساخت خانه یا استخراج سنگ/آهن، ابتدا موجودی کیف خود را بررسی می‌کند، کمبود چوب را از درختان جمع می‌کند، الوار و چوب‌دستی و کلنگ می‌سازد و سپس بلوک‌ها را جای‌گذاری می‌کند.
- **مدیریت اولویت و بازگشت به کار قبلی**: هنگام خطر فوری یا حمله هیولا، تسک ساخت‌وساز به حالت تعلیق (`SUSPENDED`) می‌رود و پس از رفع خطر خودکار ادامه می‌یابد.

## راهنمای نصب سریع

### نسخه جاوا (Fabric 1.20.6)
۱. ماینکرفت `1.20.6` به همراه `Fabric Loader 0.19.5+` و `Fabric API` نصب کنید.
۲. فایل `ai-player-0.2.0.jar` را داخل پوشه `mods` قرار دهید.
۳. وارد بازی شوید و مستقیماً در چت بنویسید:
- `بیا پیشم.` / `دنبالم بیا.`
- `۱۶ تا چوب جمع کن.`
- `ابزار بهتر بساز.`
- `برام یک خونه شیک بساز.`
- `شب از من محافظت کن.`
- یا از دستور `/aiplayer status` برای مشاهده وضعیت واقعی استفاده کنید.

### نسخه بدراک (Bedrock 1.21+)
۱. روی فایل `AIPlayer-Bedrock-0.2.0.mcaddon` کلیک کنید تا هر دو پک رفتاری و منابع وارد ماینکرفت بدراک شوند.
۲. هر دو پک را در تنظیمات دنیای خود فعال کنید (نیازی به فعال کردن گزینه‌های آزمایشی Beta نیست).
۳. در بازی دستور `/function aiplayer/spawn` را بزنید و با `/scriptevent aiplayer:cmd ۱۶ تا چوب جمع کن` به همراه خود فرمان بدهید.
