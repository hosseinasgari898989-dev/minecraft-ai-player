# AI Player for Minecraft 1.20.6

This project is a Fabric mod for Minecraft Java Edition 1.20.6.

## Current stage

The first build verifies the mod pipeline with:

    /aiplayer hello

Later stages will add an in-game player-like companion, behavior, memory, and a local AI backend.

## Build

The GitHub Actions workflow builds the mod with Java 21 and publishes the JAR as an artifact.
